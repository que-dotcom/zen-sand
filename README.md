# Zen Sand

禅の砂庭をモチーフにしたブラウザゲーム。
セルオートマトンによるリアルタイム物理シミュレーションで、砂を積み、水を流し、
熊手で砂紋を刻み、そして「散」ですべてを風に還す。

Vanilla JS のみ。ビルド不要で、ブラウザで開けばそのまま動く。

## 起動方法

ES モジュールを使っているため、`file://` ではなくローカルサーバ経由で開くこと。

```bash
python -m http.server 8080
# または
npx serve .
```

`http://localhost:8080` を開く。

## 画面の見かた

下部のバーは3行構造になっている。

```
基本  火  生命  気液  岩石  電気  侘寂  道具    ← グループタブ（選択中は下線）
●砂  ●水  ●雪  ●壁                            ← 選択中グループの素材（最大6個）
ブラシ ⊖ 3 ⊕ │ 🎬 🧪 ☁ 🔔 🍃  クリア          ← 操作
```

タブは表示を切り替えるだけで、実際に描くものは素材を選ぶまで変わらない。
素材を選ぶと、その素材が属するグループのタブが自動で開く。

## 操作

| 操作 | 効果 |
|---|---|
| クリック / ドラッグ | 選択中の素材を置く（熊手なら砂紋を刻む） |
| `T` | **温度ビュー**と通常画面を切り替える（設定画面 ⚙ からも切り替えられる）。素材を 1 キーで直接選ぶ操作（`1`〜`8`・`q`〜`c` など）は無効で、素材は下部バーから選ぶ |
| ⊖ / ⊕ | ブラシサイズを 1〜8 の範囲で増減 |
| 🎬 | シナリオを選ぶ |
| 🧪 | **実験帳**を開始する。お題の途中は⏭（スキップ）、成功後は「次へ ➜」に変わる |
| ☁ | 雨モード。選択中の素材が画面上から降り注ぐ（壁・消・熊手のときは降らない） |
| 1× | **倍速**。押すたびに 1×→2×→4×…と **2 の乗数**で上がり（その端末の上限まで）、最後に**最速**を選べて、その次は 1× に戻る。最速は特定の数値ではなく、その端末が 60fps を保てる最大の速さにいつも自動で合わせる（盤面が重くなれば遅くなり、軽くなれば速くなる。ボタンには `最速 116×` のようにいまの速さも出る）。上限は固定値ではなく、表示 60fps を保てる範囲を実測して端末ごとに決まる。盤面が急に重くなれば上限は即座に下がり（1 ステップのコストは平均と直近の最大値の大きいほうで見積もる）、1 フレームに回すステップは時間でも打ち切るので固まらない。選んだ倍速は「希望」として覚えていて、上限に抑えられているときはボタンに「実際/希望」（例: `4/16×`）と出て、軽くなれば自動で希望まで戻る。描画は常に 60fps、シミュレーションだけが速くなる |
| 🔔 | 音（水琴窟）のオン/オフ。雫・砂擦れ・風・おりんをその場で合成している |
| ⚙ | **設定**画面を開く（いまは温度ビューの切り替え） |
| 🍃 | **散** — 風がすべてを掃き消し、無に還る。終わったら鐘が鳴る |
| クリア | 盤面を即座に空にする（実験帳も終了する） |

## 素材

パレットに並ぶのは 8 グループ・33 種。

### 基本

| 素材 | 挙動 |
|---|---|
| 砂 | 重力で落下して積み上がる。水を押しのける。溶岩に触れると砂岩になる |
| 水 | 流動的に広がる。火を消す。雪や氷が隣にあると凍りつく |
| 雪 | ゆっくり舞い落ちる。火で溶け、水や溶岩の上に落ちると水になる |
| 壁 | 動かない障壁。何にも侵されない |

### 火

| 素材 | 挙動 |
|---|---|
| 火 | 上昇して消える。可燃物を燃やし、雪や氷を溶かす |
| 油 | 水面に浮く軽い液体。よく燃える。氷が隣にあると凍って動かなくなる |
| 溶岩 | ゆっくり流れる。水に触れると石と蒸気、雪に触れると黒曜石になる。砂をガラスや砂岩に変える |
| 炭 | 落下して積もる。火や雷が触れると燃え出す |

### 生命

| 素材 | 挙動 |
|---|---|
| 土(落) | 砂と同じく落下する土。植物が根を張れる。水気がなく温まると乾いて砂に、強く熱すると灰になる |
| 土(固) | 落ちない土。足場と水分源になる |
| 種 | 土と水が揃うと発芽し、植物に育ってやがて花を咲かせる |
| 菌 | 地面を這うように横へ広がる。油に触れると発光菌になる。火・溶岩・氷で死ぬ |
| 酸植物 | 隣の植物を侵食して自分に変える。水が触れると暗黒植物に戻る |

### 気液

| 素材 | 挙動 |
|---|---|
| 蒸気 | 上昇する。**高度**が露点（画面の高さの半分）を超えると凝結して「雲」になる。高いほど雲になりやすい。天井に詰まると水滴になって落ちる |
| 酸 | 多くの素材を溶かす。金属を錆びさせる |
| 泥 | 粘性のある流体。火で焼くと石、溶岩に触れると玄武岩になる |
| 氷 | 火・溶岩・酸・雷で水に戻る。隣の水をゆっくり凍らせ、蒸気を凝結させる |

### 岩石

| 素材 | 挙動 |
|---|---|
| 黒曜石 | 溶岩でのみ溶ける。酸・雷・水に完全耐性 |
| 砂岩 | 水でじわじわ侵食されて砂に戻る。酸で速く溶け、溶岩で再加熱するとガラスになる |
| 玄武岩 | 溶岩で再溶融、酸で泥になる |
| 水源 | 3%/フレームで隣に水を生み続ける永久水源 |
| 溶岩源 | 地熱噴出口。水が触れると石を作らず直接蒸気に変える |

### 電気

| 素材 | 挙動 |
|---|---|
| 金属 | 電気を通す。水や泥に触れると錆びる |
| 雷 | 金属を伝って走る。砂をガラスに、菌を発光菌に変える |
| 金 | 最も重い粘性の液体。石の割れ目に挟まれると凝固して金継ぎになる。酸には侵されない |

### 侘寂

| 素材 | 挙動 |
|---|---|
| 桜種 | 桜の木に育ち、花びらを散らす |
| 花びら | ひらひらと舞い落ちる |
| 蛍 | 明滅しながら漂う |
| 花粉 | 逆重力で上昇・横に漂う。花を受粉させ、植物の開花を早める。寿命がある |
| 間 | 石や壁で囲まれた密閉空間でしか存在できない聖域。中では火が浄化され、灰は無に還り、暗黒植物は光に戻り、種は白い桜として直接開花する。花びらは落ちずに漂う |
| 鯉 | 水の中を泳ぎ回る。胴体を引きながら進む |

### 道具

| 道具 | 挙動 |
|---|---|
| 熊手 | 物理には触れず、静止した砂の色だけを書き換えて砂紋を刻む。何度掻いても潰れない |
| 消 | セルを削除する |

## 反応でのみ生まれる素材

パレットには無く、素材どうしの反応でだけ現れるものが 16 種ある。

煙 / 灰 / 石 / ガラス / 植物 / 暗黒植物 / 発光菌 / 花 / 暗黒花 / 電撃 / 錆 / 桜の木 / 鯉の胴体 / 振動波 / 金継ぎ / 雲

例えば ——

- 溶岩 + 水 → **石** + 蒸気
- 蒸気が露点高度を超える → **雲**。雲が厚くなると雨粒を落とし、暖かい低空や熱源の近くでは蒸発して蒸気に戻る（高度 0 = 画面下端、1 = 上端）
- 溶岩 + 砂、または 雷 + 砂 → **ガラス**
- 溶岩 + 雪 → 黒曜石 + 蒸気
- 金属 + 水（または泥・蒸気・酸） → **錆**
- 菌 + 雷、または 菌 + 油 → **発光菌**
- 種 + 土 + 水 → **植物** → **花**
- 火 + 泥 → **石**、溶岩 + 泥 → 玄武岩
- 石の割れ目に注いだ金 → **金継ぎ**（雷の振動波を通し、溶岩で金に還る）

## 温度 🌡

すべてのセルが温度（0〜255 の相対値）を持ち、隣のセルへ熱が伝わる。空きセルは気温で、気温は**高度が上がるほど下がる**（地表 108 → 最上段 86）。
素材が動くと温度も一緒に動き、温度が閾値を越えると相が変わる。

| 温度 | 起きること |
|---|---|
| 氷点（80）以下 | 水が氷になる。氷・雪は置いた直後は氷点のすぐ下（72〜74）。氷点を超えると融けはじめるが、融けきるには**融解の潜熱**ぶんの熱が要り（その間、温度は氷点に留まる）、熱を受けた表面から順に、少しずつ水色がかって融けていく。**凍結にも同じ潜熱を使う**ので、水は氷点以下になっても一瞬では凍らない。隣に氷や雪があるだけでは凍らず、暖かい環境では氷のほうが減っていく。雪は、氷点に近い冷たい池の水面では氷になり、暖かい池ではただ水になる |
| 露点（96）以下 | 冷えた蒸気が凝結して雲になる（上空ほど凝結しやすい） |
| 沸点（150）以上 | 水が沸騰して蒸気になる。体積は **25 倍**（水蒸気爆発）。蒸発の潜熱で周りの熱源から熱を奪う |
| 約 165〜200 | 油・炭・植物などの可燃物が発火する |
| 215 以上 | 石が溶けて溶岩になる。溶岩は 255 で生まれ、170 以下に冷えると石に固まる |

- 画面の外側とは熱をやり取りしない（断熱）。端のセルが外気で冷えたり、外から熱が入ったりはしない。
- 素材ごとに**熱伝導率**（金属はよく伝え、雪や溶岩の表面は伝えにくい）と**熱容量**（水や氷は温まりにくい）が違う。
- 溶岩は水に触れると水を沸騰させ、岩に触れると溶かす。そのたびに熱を失い、使い切ると固まる。冷えるほど色が暗くなる。
- 蒸気は 25 セルが凝結して水 1 粒に戻る（質量は増えない）。
- **環境の気温** — ⚙ 設定画面の「気温（地表）」スライダー（30〜200、標準 108）で、環境の気温を変えられる。高度による下がり方はそのままで、全体が上下にずれる。
  氷点（80）を下回ると水が凍り、沸点（150）を上回ると水が沸騰する。空気は設定した気温にすぐなるが、素材の温度は熱交換でゆっくり近づく。「標準に戻す」で 108 に戻る（ページを開き直しても標準に戻る）。
- **デバッグ: 温度ビュー** — 下部バーの ⚙ から開く**設定画面**の「温度ビュー」をオンにすると、盤面が温度のヒートマップに切り替わる。
  青（冷）→ 緑 → 黄（沸点付近）→ 赤 → 白（溶岩）で、空気は暗く描く。白い線が沸点、水色の線が氷点の等温線。
  カーソルを当てたセルは十字で示し、右上のパネルに温度・素材・気温・高度と「いま何が起きうる温度帯か」を表示する。
- 数値の基準は `src/materials/climate.js`、素材ごとの性質は `src/thermal.js` にある。

## 技術スタック

- Vanilla JS（ES Modules）— フレームワーク・ビルドツールなし
