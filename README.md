# Zen Sand

禅の砂庭をモチーフにした、セルオートマトンのブラウザゲームです。素材を置き、流し、反応させて庭を育てます。

## 起動方法

ES Modules を使うため、ローカルサーバーで起動してください。

```bash
python -m http.server 8080
```

ブラウザで `http://localhost:8080` を開きます。Node.js があれば `npx serve .` でも起動できます。

## 遊び方

- パレットまたは対応キーで素材を選び、クリック／ドラッグで配置します。
- ブラシスライダーで配置範囲を変えられます。
- ☁ は選択中の落下・流動素材を雨として降らせます。
- 🎬 は4本のシナリオを開きます。🧪 は実験帳を開始します。お題の途中は⏭でスキップでき、
  成功後は「次へ ➜」に変わり、押すまで反応を眺められます。
- 🔔 は音のオン／オフ、🍃 は庭を風で掃き消す儀式、クリアは盤面を空にして実験帳も終了します。

## 実験帳 🧪

化学反応を情景の中で試す練習モードです。開始すると画面全体に舞台が現れ、正しい素材を注いで生成物を十分に作ると成功します。14題すべてを終えると皆伝です。

| お題 | 注ぐ素材 | 主な生成物 |
|---|---|---|
| 野火 | 火 | 炎 |
| 油田の雷鳴 | 雷 | 炎 |
| 湯けむり | 火／溶岩 | 蒸気 |
| 溶岩流 | 水 | 石 |
| 雷とガラス | 雷 | ガラス |
| 砂の炉 | 溶岩 | 砂岩 |
| 火口 | 雪 | 黒曜石 |
| 泥田 | 溶岩 | 玄武岩 |
| 夜光洞 | 油 | 発光菌 |
| 畑 | 種 | 植物・花 |
| 墨田の夜 | 水 → 種 | 暗黒植物 |
| 凍る池 | 雪 | 氷 |
| 雷鳴の池 | 雷 | 電撃 |
| 金継ぎ | 金 | 金継ぎ |

設計・追加手順・検証方法は [実験帳お題作成要領](docs/practice-drill-guide.md) にあります。
今回までの変更内容は [実験帳 変更メモ](docs/practice-mode-changelog.md) にまとめています。

墨田の夜は二段階です。まず画面下の黒い炭田へ水 [2] を流して黒い墨泥を作り、
その上へ種 [w] を蒔いてください。墨泥が十分にできると、案内が自動で2番目の手順へ切り替わります。

## 素材

現在は33種類（熊手と消去を含む）です。パレットでは燃焼、生命、電気、気液、岩石、侘寂、ツールに分かれています。基本的な操作は `1` 砂、`2` 水、`3` 雪、`4` 火、`6` 溶岩、`t` 雷、`w` 種、`n` 金、`0` 消去です。

## 検証

実験帳とシナリオの回帰テストは一時的に ESM 設定を置いて実行します。詳細は [実験帳お題作成要領](docs/practice-drill-guide.md#6-お題の追加手順チェックリスト) を参照してください。
