# Zen Sand

禅の砂庭をモチーフにしたブラウザゲーム。
セルオートマトンによるリアルタイム物理シミュレーションで、砂を積み、水を流し、
熊手で砂紋を刻み、そして「散」ですべてを風に還す。

Vanilla JS のみ。ビルド不要で、ブラウザで開けばそのまま動く。

## 起動方法

ES モジュールを使っているため、`file://` ではなくローカルサーバ経由で開くこと。

```bash
python -m http.server 8080
# または
npx serve .
```

`http://localhost:8080` を開く。

## 画面の見かた

下部のバーは3行構造になっている。

```
基本  火  生命  気液  岩石  電気  侘寂  道具    ← グループタブ（選択中は下線）
●砂  ●水  ●雪  ●壁                            ← 選択中グループの素材（最大6個）
ブラシ ⊖ 3 ⊕ │ 🎬 🧪 ☁ 🔔 🍃  クリア          ← 操作
```

タブは表示を切り替えるだけで、実際に描くものは素材を選ぶまで変わらない。
素材を選ぶと、その素材が属するグループのタブが自動で開く。

## 操作

| 操作 | 効果 |
|---|---|
| クリック / ドラッグ | 選択中の素材を置く（熊手なら砂紋を刻む） |
| `1`〜`8` / `q`〜`c` などのキー | 素材を直接選ぶ（下の表の「キー」列） |
| ⊖ / ⊕ | ブラシサイズを 1〜8 の範囲で増減 |
| 🎬 | シナリオを選ぶ |
| 🧪 | **実験帳**を開始する。お題の途中は⏭（スキップ）、成功後は「次へ ➜」に変わる |
| ☁ | 雨モード。選択中の素材が画面上から降り注ぐ（壁・消・熊手のときは降らない） |
| 🔔 | 音（水琴窟）のオン/オフ。雫・砂擦れ・風・おりんをその場で合成している |
| 🍃 | **散** — 風がすべてを掃き消し、無に還る。終わったら鐘が鳴る |
| クリア | 盤面を即座に空にする（実験帳も終了する） |

## 実験帳 🧪

化学反応を情景の中で試す練習モード。開始すると画面全体に舞台が現れ、正しい素材を注いで生成物を十分に作ると成功。成功すると反応のリプレイと、ひらがなの解説が出るポップアップが表示される。16題すべてを終えると皆伝になる。

| お題 | 注ぐ素材 | 主な生成物 |
|---|---|---|
| 野火 | 火 | 炎 |
| 油田の雷鳴 | 雷 | 炎 |
| 湯けむり | 火／溶岩 | 蒸気 |
| 溶岩流 | 水 | 石 |
| 雷とガラス | 雷 | ガラス |
| 砂の炉 | 溶岩 | 砂岩 |
| 火口 | 雪 | 黒曜石 |
| 泥田 | 溶岩 | 玄武岩 |
| 夜光洞 | 油 | 発光菌 |
| 畑 | 種 | 植物・花 |
| 墨田の夜 | 水 → 種 | 暗黒植物 |
| 凍る池 | 雪 | 氷 |
| 雷鳴の池 | 雷 | 電撃 |
| 錆の海 | 金属 | 錆 |
| 蛍の沢 | 水 | 蛍 |
| 金継ぎ | 金 | 金継ぎ |

墨田の夜だけ二段階。まず画面下の黒い炭田へ水 `2` を流して墨泥を作り、その上へ種 `w` を蒔く。墨泥が十分にできると案内が自動で2番目の手順に切り替わる。

設計・追加手順・検証方法は [実験帳お題作成要領](docs/practice-drill-guide.md)、
これまでの変更内容は [実験帳 変更メモ](docs/practice-mode-changelog.md) にある。

## 素材

パレットに並ぶのは 8 グループ・33 種。

### 基本

| 素材 | キー | 挙動 |
|---|---|---|
| 砂 | `1` | 重力で落下して積み上がる。水を押しのける。溶岩に触れると砂岩になる |
| 水 | `2` | 流動的に広がる。火を消す。雪や氷が隣にあると凍りつく |
| 雪 | `3` | ゆっくり舞い落ちる。火で溶け、水や溶岩の上に落ちると水になる |
| 壁 | `8` | 動かない障壁。何にも侵されない |

### 火

| 素材 | キー | 挙動 |
|---|---|---|
| 火 | `4` | 上昇して消える。可燃物を燃やし、雪や氷を溶かす |
| 油 | `5` | 水面に浮く軽い液体。よく燃える。氷が隣にあると凍って動かなくなる |
| 溶岩 | `6` | ゆっくり流れる。水に触れると石と蒸気、雪に触れると黒曜石になる。砂をガラスや砂岩に変える |
| 炭 | `7` | 落下して積もる。火や雷が触れると燃え出す |

### 生命

| 素材 | キー | 挙動 |
|---|---|---|
| 土(落) | `q` | 砂と同じく落下する土。植物が根を張れる |
| 土(固) | `a` | 落ちない土。足場と水分源になる |
| 種 | `w` | 土と水が揃うと発芽し、植物に育ってやがて花を咲かせる |
| 菌 | `e` | 地面を這うように横へ広がる。油に触れると発光菌になる。火・溶岩・氷で死ぬ |
| 酸植物 | `p` | 隣の植物を侵食して自分に変える。水が触れると暗黒植物に戻る |

### 気液

| 素材 | キー | 挙動 |
|---|---|---|
| 蒸気 | `y` | 上昇し、天井で冷えて水滴になって落ちる |
| 酸 | `u` | 多くの素材を溶かす。金属を錆びさせる |
| 泥 | `i` | 粘性のある流体。火で焼くと石、溶岩に触れると玄武岩になる。隣の雪を泥に変える |
| 氷 | `o` | 火・溶岩・酸・雷で水に戻る。隣の水をゆっくり凍らせ、蒸気を凝結させる |

### 岩石

| 素材 | キー | 挙動 |
|---|---|---|
| 黒曜石 | `s` | 溶岩でのみ溶ける。酸・雷・水に完全耐性 |
| 砂岩 | `d` | 水でじわじわ侵食されて砂に戻る。酸で速く溶け、溶岩で再加熱するとガラスになる |
| 玄武岩 | `f` | 溶岩で再溶融、酸で泥になる |
| 水源 | `g` | 3%/フレームで隣に水を生み続ける永久水源 |
| 溶岩源 | `h` | 地熱噴出口。水が触れると石を作らず直接蒸気に変える |

### 電気

| 素材 | キー | 挙動 |
|---|---|---|
| 金属 | `r` | 電気を通す。水や泥に触れると錆びる |
| 雷 | `t` | 金属を伝って走る。砂をガラスに、菌を発光菌に変える |
| 金 | `n` | 最も重い粘性の液体。石の割れ目に挟まれると凝固して金継ぎになる。酸には侵されない |

### 侘寂

| 素材 | キー | 挙動 |
|---|---|---|
| 桜種 | `j` | 桜の木に育ち、花びらを散らす |
| 花びら | `k` | ひらひらと舞い落ちる |
| 蛍 | `l` | 明滅しながら漂う |
| 花粉 | `z` | 逆重力で上昇・横に漂う。花を受粉させ、植物の開花を早める。寿命がある |
| 間 | `x` | 石や壁で囲まれた密閉空間でしか存在できない聖域。中では火が浄化され、灰は無に還り、暗黒植物は光に戻り、種は白い桜として直接開花する。花びらは落ちずに漂う |
| 鯉 | `c` | 水の中を泳ぎ回る。胴体を引きながら進む |

### 道具

| 道具 | キー | 挙動 |
|---|---|---|
| 熊手 | `v` | 物理には触れず、静止した砂の色だけを書き換えて砂紋を刻む。何度掻いても潰れない |
| 消 | `0` | セルを削除する |

## 反応でのみ生まれる素材

パレットには無く、素材どうしの反応でだけ現れるものが 15 種ある。

煙 / 灰 / 石 / ガラス / 植物 / 暗黒植物 / 発光菌 / 花 / 暗黒花 / 電撃 / 錆 / 桜の木 / 鯉の胴体 / 振動波 / 金継ぎ

例えば ——

- 溶岩 + 水 → **石** + 蒸気
- 溶岩 + 砂、または 雷 + 砂 → **ガラス**
- 溶岩 + 雪 → 黒曜石 + 蒸気
- 金属 + 水（または泥・蒸気・酸） → **錆**
- 菌 + 雷、または 菌 + 油 → **発光菌**
- 種 + 土 + 水 → **植物** → **花**
- 火 + 泥 → **石**、溶岩 + 泥 → 玄武岩
- 石の割れ目に注いだ金 → **金継ぎ**（雷の振動波を通し、溶岩で金に還る）

## シナリオ

🎬 から選べる幕構成のシナリオ。素材を使ったりイベントが起きたりすると次の幕へ進む。

| | シナリオ | 内容 | 難度 |
|---|---|---|---|
| 🌸 | 桜と蛍 | 花・宵・蛍の四幕劇 | ★ |
| 🏺 | 金継ぎ | 破れ・金・景色の五幕劇 | ★★ |
| 🌙 | 凍った呪いの森 | 呪い・結晶・解放の三幕劇 | ★★ |
| 🌋 | 最後の楽園 | 汚染・封印・再生の三幕劇 | ★★★ |

## 技術スタック

- Vanilla JS（ES Modules）— フレームワーク・ビルドツールなし
- Canvas API + ImageData による高速ピクセル描画
- セルオートマトン（Falling Sand アルゴリズム）
- Web Audio API による生成音響（サンプル素材を持たず、その場で合成している）

## 検証

実験帳とシナリオの回帰テストは、リポジトリ直下に一時 `package.json`（`{"type":"module"}`）を
置いて `node tests/practice.test.mjs` / `node tests/scenario.test.mjs` で実行する。
詳細は [実験帳お題作成要領](docs/practice-drill-guide.md) の追加手順を参照。
