# 実験帳 変更メモ

最終更新: 2026-08-11

実験帳（🧪）に行った変更と、確認済みの内容を簡潔に残すメモです。

## 現在の仕様

- お題は **14題**。すべて画面下から広がる情景の中で反応を試す。
- 成功条件は、生成物セル数が開始時の数から一定数以上増えること。
- 成功時はおりんが鳴るが、**自動で次題へ進まない**。
  - 🧪ボタンは成功後に **「次へ ➜」** へ変わる。
  - プレイヤーが押すまで、反応をそのまま観察できる。
  - 挑戦中の同じ場所のボタンは **⏭** で、その題をスキップする。
  - クリアは実験帳を終了して盤面を空にする。

## 追加したお題

| お題 | 操作 | 観察する変化 |
|---|---|---|
| 油田の雷鳴 | 油田に雷 `[t]` | 油が広範囲の炎へ変わる |
| 夜光洞 | 菌床に油 `[5]` | 菌が青緑色の発光菌へ変わる |
| 墨田の夜 | 炭田に水 `[2]`、続けて種 `[w]` | 炭→墨泥→暗黒植物 |
| 砂の炉 | 砂丘に溶岩 `[6]` | 砂が黄褐色の砂岩へ変わる |

## 墨田の夜の手順

1. 画面下の**黒い炭田**へ、水 `[2]` を流す。
2. 炭が黒い墨泥に十分変わると、案内が自動で切り替わる。
3. **黒い墨泥の上**へ、種 `[w]` を蒔く。
4. 暗黒植物が育つと成功。成功後は「次へ ➜」を押すまで観察できる。

## 検証済み

- 新規3題の反応候補は、各8回の単体試験で全回成立。
- 砂の炉は8回の単体試験で全回成立（砂岩は36〜51セルまで増加）。
- 実験帳全14題を機械プレイで2回連続完走。
- 成功後240フレーム待っても自動遷移しないことをテスト。
- 「次へ」操作によってのみ次題へ進むことをテスト。
- 金継ぎ・シナリオの回帰テストは20/20成功。
