# 実験帳 変更メモ

最終更新: 2026-08-12

実験帳（🧪）に行った変更と、確認済みの内容を簡潔に残すメモです。

## 現在の仕様

- 学習モード化: 反応が始まった瞬間に、ひらがなの反応トーストを表示する。
- 成功から90フレーム後に、直近約6秒の反応をループ再生する全画面ポップアップを表示する。
  子ども向けのひらがな解説を読み、「つぎへ ➜」で次題へ進める。
- ブラシの初期サイズは5。キャンバスは下部バーの上端で終わり、盤面がバーの裏に隠れない。

- お題は **24題**。すべて画面下から広がる情景の中で反応を試す。
- 成功条件は、生成物セル数が開始時の数から一定数以上増えること。
- 成功時はおりんが鳴るが、**自動で次題へ進まない**。
  - 🧪ボタンは成功後に **「次へ ➜」** へ変わる。
  - プレイヤーが押すまで、反応をそのまま観察できる。
  - 挑戦中の同じ場所のボタンは **⏭** で、その題をスキップする。
  - クリアは実験帳を終了して盤面を空にする。

## 墨田の夜の手順

1. 画面下の**黒い炭田**へ、水 `[2]` を流す。
2. 炭が黒い墨泥に十分変わると、案内が自動で切り替わる。
3. **黒い墨泥の上**へ、種 `[w]` を蒔く。
4. 暗黒植物が育つと成功。成功後は「次へ ➜」を押すまで観察できる。

## 検証済み

- 新規3題の反応候補は、各8回の単体試験で全回成立。
- 砂の炉は8回の単体試験で全回成立（砂岩は36〜51セルまで増加）。
- 錆の海・蛍の沢は各8回の単体試験で全回成立（正答プレイは120〜450フレームで到達）。
- 実験帳全24題を機械プレイで3回連続完走（当初9題増の25題だったが「花の風」を検収で差し戻し）。
- 成功後240フレーム待っても自動遷移しないことをテスト。
- 「次へ」操作によってのみ次題へ進むことをテスト。
- 金継ぎ・シナリオの回帰テストは20/20成功。
